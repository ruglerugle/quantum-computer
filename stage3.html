STAGE 3量子はどこにいるのか
実機の中身
🎯 ミッション
矢印の表・ゲート・測定が、実物の「何」に対応するのかを、超伝導量子ビットを例に言えるようになろう。「量子」の居場所――エネルギーのとびとびの段と、波として両方の段に居られること――を指させれば合格。
未達成
うさ美
ここまで、矢印の表とゲートで「計算のルール」を学びました。でも正直に言うと、実物がまったく想像できません。実験室にある量子コンピュータの中で、何が矢印の表で、ゲートを「当てる」とは何をすることなんですか？ そもそも――「量子」はどこにいるんですか？
ねこ博士
今日はその解剖の日にしよう。いちばん普及している超伝導方式の量子ビット1個を、部品まで分解する。
正体は、チップの上に印刷された小さな電気回路だ。部品は実質2つ。電気をためるコンデンサと、電流の通り道になるコイルの親戚。この2つを輪にすると、電気が行ったり来たりと振動する回路ができる。振り子の電気版だね。ここまでは量子でも何でもない、ラジオにも入っている古典的な部品だよ。
うさ美
電気の振り子……が量子ビットには、まだ見えません。振り子の揺れの大きさは連続的に変えられます。0と1のような「はっきり分かれた2つの状態」が、どこにもありません。
ねこ博士
その通り。だから2つの仕掛けで量子の世界に持ち込む。仕掛けの1つめは冷却だ。この回路を、絶対零度よりわずか100分の1度ほど高いだけの温度（約−273.14℃）まで冷やす。すると2つのことが起きる。まず回路が超伝導になって電気抵抗が完全にゼロになり、振動が擦り減らなくなる。そして熱の雑音が消えて、回路の振る舞いを量子力学が支配し始める。
量子力学の世界では、振動のエネルギーは連続には増やせない。とびとびの決まった段しか取れないんだ。エネルギーの階段だね。実は「量子」という言葉自体が、この「とびとびのかたまり」という意味なんだよ。
うさ美
「量子」の名の由来は、エネルギーの階段……。では、その階段の段が |0⟩ と |1⟩ ですか？ でも階段なら、3段目も4段目もありますよね。2つだけを選べる理由がありません。
ねこ博士
そこが仕掛けの2つめだ。ただの振り子回路には致命的な欠点がある――段の間隔が全部同じなんだ。1段目に上げようと「段差1つぶんのエネルギー」を送ると、同じ段差で2段目、3段目へも上がってしまい、下の2段だけを選べない。
そこで、この方式の心臓部ジョセフソン接合が登場する。2枚の超伝導体で、ごく薄い絶縁の膜を挟んだ部品だ。普通なら電気は絶縁膜を通れないが、量子の世界では波がしみ出して通り抜ける。この部品をコイルの代わりに入れると、振動の性質が変わって、階段の間隔が不揃いになる。1段目までの段差と、2段目までの段差が違ってくるんだ。
すると――「1段目までの段差」にぴったりのエネルギーだけを送り込めば、2段目より上へは決して行かない。下の2段だけが、外の世界から選べる。この下2段こそが |0⟩（下の段）と |1⟩（上の段）だよ。この回路にはトランズモンという名前がついている。
縦方向がエネルギー。左の「ただの振動回路」は段の間隔がすべて同じなので、1段目に上げるためのエネルギーが2段目・3段目へのはしごにもなってしまい、2つの状態を選び出せない。右はコイルの代わりにジョセフソン接合を入れた回路（トランズモン）。段の間隔が不揃いになるため、いちばん下の段差にぴったり合わせたエネルギーは、下2段の行き来しか起こせない。こうして無限にある段の中から |0⟩ と |1⟩ の2段だけが「使える状態」として切り出される。
うさ美
|0⟩ と |1⟩ の正体は、超伝導回路のエネルギーの下2段……。では「重ね合わせ」は実物では何ですか？ 段と段のあいだに浮かんでいる、わけではないですよね。
ねこ博士
浮かんでいるのではなく、両方の段に、波として同時に居る。超伝導の回路の中では、何十億個もの電子がペアを組み、全体がそろってたった1つの波として振る舞っている。そしてこの波は、「下の段の振動」と「上の段の振動」を同時に含むことができる――これが重ね合わせの実物だ。
ここで、前ステージまでの言葉と実物がつながる。矢印の表とは、この1つの波の中身の帳簿なんだよ。|0⟩ の矢印の長さは「波のうち、下の段の振動がどれだけ入っているか」、|1⟩ の矢印は上の段のぶん。表は紙の上の抽象ではなく、チップの上で振動している波の成分表だったわけだ。
うさ美
次はゲートです。H や X を「当てる」とは、実物では何をすることなんですか。
ねこ博士
電波を1発当てる。それだけだ。|0⟩ と |1⟩ の段差はエネルギーの量として決まっていて、それに対応する電波の周波数は数ギガヘルツ――スマホの電波に近いマイクロ波になる。この段差にぴったりの周波数の電波を回路に送り込むと、共鳴が起きる。ブランコと同じで、リズムの合った押しだけが揺れを育てるんだ。
共鳴しているあいだ、回路の波は下の段と上の段のあいだで連続的に混ざっていく。だから、電波を当てる時間の長さで、矢印の混ざり具合が決まる。途中まで混ぜて止めれば五分五分の重ね合わせ（H にあたる混ぜ方）、完全に入れ替わるまで当てれば X。
つまりゲートとは、長さと形を精密に設計した電波パルスを1発撃つこと。ゲート1回が数十ナノ秒（1億分の数秒）と言われるのは、このパルス1発の長さのことなんだよ。
うさ美
……これで、ずっと引っかかっていたことが1つ解けました。「1回のゲートで表全体が書き換わる」と言われても、機械が全部の行を素早く処理しているように聞こえていたんです。違うんですね。パルスは波全体に働く。そして表は波の帳簿なのだから、|0⟩ の成分と |1⟩ の成分を「順番に」処理する余地が、そもそも存在しない。
ねこ博士
それが今日いちばん持ち帰ってほしいことだ。装置には「波の成分を1つずつ触る」ボタンなど存在しない。波への操作は、いつでも波全体への操作――量子コンピュータの「同時に」は、機械の努力ではなく、波という存在の性質そのものなんだ。
ついでに言うと、CNOT のような2量子ビットのゲートは、隣り合う2つの回路を配線でつないでおいて、結合を一瞬だけ働かせるパルスを撃つ。「相手の段に応じて自分の波の回り方が変わる」という相互作用が、あの表の書き換えの実物だよ。
|0⟩の矢印 1.00 |1⟩の矢印 0.00 0が出る確率 100% 1が出る確率 0%
パルスの時間
スライダーが「段差にぴったりの周波数のマイクロ波を当て続けた時間」。|0⟩ から出発して、当てるほど波は上の段へ移っていき、矢印の表が連続的に書き換わる。途中（4分の1周）で止めれば五分五分＝Hにあたる混ぜ方、半周ぶん当てれば完全な入れ替え＝X。さらに当て続けると1周して元に戻る。ゲートの正体は「パルスの長さの設計」であり、H と X は同じつまみの止め位置の違いにすぎない。実機ではこの1周が数十ナノ秒で回る。
うさ美
最後は測定です。「読み出すと0か1が出る」の実物は、何をしているんですか。
ねこ博士
量子ビットの隣に、読み出し専用の小さなマイクロ波の空洞（共振器）をつないでおく。この空洞に弱い電波を通すと、面白いことが起きる。量子ビットが |0⟩ か |1⟩ かで、空洞の共鳴の周波数がごくわずかにずれるため、通り抜けてきた電波の波形が変わるんだ。その変化を増幅して読み取れば、0か1かが分かる。
そして前の旅の言葉で言えば――電波に手がかりが乗って外の世界へ出た瞬間、道筋の区別がついて、状態は出た方に確定する。測定装置とは、手がかりが環境へ漏れ出す場所を、わざと1か所だけ作ってある仕掛けなんだよ。ふだんは全力で密閉している箱に、読みたいときだけ開ける小窓があるわけだ。
うさ美
まとめます。
①矢印の表＝超伝導回路の中の1つの波の成分帳簿。|0⟩ と |1⟩ は、エネルギーの階段の下2段。
②ゲート＝段差にぴったりの周波数のマイクロ波パルスを、設計した時間だけ当てること。
③測定＝読み出し空洞を通る電波の変化として、手がかりをわざと外に出すこと。
④そして「量子」の居場所は2つ――エネルギーがとびとびの段になること（名前の由来）と、回路の波が両方の段に同時に居られること。この2つが、ふつうの電気回路にはない量子の取り分なんですね。
ねこ博士
完璧な対応表だ。付け加えると、方式は超伝導だけではない。電磁場の罠に浮かべたイオン1個のエネルギー状態を使うイオン方式（パルスはレーザー光）、レーザーのピンセットで原子を並べる中性原子方式、光そのものを使う光方式――どれも役者は違うが、「とびとびの2状態を選び、波の重ね合わせを保ち、共鳴パルスで操る」という骨組みは共通だよ。
そして、鋭い人はもう気づいているはずだ。何十億個の電子がそろった波を、空気の分子1個、光子1個にも乱されずに保つ――これは恐ろしく難しい注文だ。だからこそ極低温で密閉するのだけれど、それでも波は少しずつ乱れていく。その戦いの話は、旅の最後のステージまで取っておこう。次のステージでは、量子ビットを2個に増やして、この旅の主役級の現象を自分の手で作ってもらう。
【実機の中身 ― 超伝導量子ビットの対応表】 ・本体＝チップ上の超伝導の振動回路。約−273.14℃（絶対零度の100分の1度上）まで冷やすと、振動のエネルギーがとびとびの段になる（＝「量子」の名の由来） ・ジョセフソン接合が段の間隔を不揃いにし、下2段だけを選べるようにする → これが |0⟩ と |1⟩（トランズモン） ・重ね合わせ＝何十億個の電子ペアがそろった1つの波が、両方の段に同時に居ること。矢印の表はこの波の成分帳簿 ・ゲート＝段差にぴったりの周波数（数ギガヘルツ）のマイクロ波パルスを設計した時間だけ当てる共鳴操作。
当てる時間で混ざり具合が決まり、H と X は止め位置の違い。1発が数十ナノ秒 ・パルスは波全体に働く。成分を1つずつ触る手段は存在しない――「同時に計算」は機械の芸当ではなく波の性質 ・測定＝読み出し空洞の電波の変化として手がかりをわざと外へ出す小窓。手がかりが出た瞬間、状態は確定する ・他方式（イオン・中性原子・光）も「とびとびの2状態＋波の重ね合わせ＋共鳴パルス」という骨組みは同じ
確認クイズ

Q1. 量子ビットの「量子」とは、実物では何を指している？

正解！ 「量子」は「とびとびのかたまり」という意味で、エネルギーの階段がその実物。超伝導回路はチップ上の目に見える配線で、原子1個でも電子1個でもない――何十億個の電子ペアがそろって1つの波として振る舞う、マクロな量子系だ。

Q2. ゲート（H や X）を「当てる」の実物は？

正解！ 共鳴だけが2つの段の行き来を起こすので、周波数は段差で決まっている。当てる時間の長さが矢印の混ざり具合を決め、途中で止めればHにあたる五分五分、半周ぶん当てればX。ゲートの設計とは、パルスの長さと形の設計だ。

Q3. 測定（読み出し）の実物は？

正解！ 量子ビットが |0⟩ か |1⟩ かで空洞の共鳴がわずかにずれ、通った電波の波形が変わる。その電波に手がかりが乗って外へ出た瞬間、状態は出た方に確定する。測定装置とは「手がかりの漏れ口を1か所だけわざと作った小窓」だ。
