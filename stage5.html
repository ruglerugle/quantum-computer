STAGE 5グローバーの探索
振幅増幅
🎯 ミッション
「当たりの矢印を反転させる」「平均のまわりで折り返す」という2手だけで、正解の矢印が育っていく仕組みを理解しよう。必要な回数が約√N であること、そしてそれが2次加速にとどまることまで説明できれば合格。
未達成
ねこ博士
今日は、誰もが本当に困っている問題を扱おう。並べ替えられていない大量の候補の中から、条件に合う1個を探す問題だ。
たとえば、電話帳から「この電話番号の持ち主は誰か」を調べるとする。電話帳は名前の五十音順に並んでいて、番号順には並んでいない。この場合、どう探すことになるかな。
うさ美
端から順に見ていくしかありません。運がよければ1件目、悪ければ最後の1件。候補が N 件あれば、平均で N の半分くらい、最悪 N 回調べることになります。
並び順に手がかりがない以上、これより速い方法はないはずです。だって、調べていない項目が当たりでない保証はどこにもないので。
ねこ博士
その推論はふつうのコンピュータについては完全に正しくて、証明もされている。N 件の総当たり探索は、N に比例する回数がどうしても必要だ。
ところが1996年、ロブ・グローバーが量子コンピュータでこれを 約√N 回に減らす方法を見つけた。N が100万なら、100万回ではなく約1000回。1兆件なら100万回だ。
うさ美
100万件を1000回で……。でも、どうやって。全部の候補に矢印を立てて重ね合わせても、そのまま測ったら100万分の1の確率で当たりが出るだけです。それでは100万回引かないと当たりません。
――ということは、測る前に当たりの矢印だけを長くする操作があるんですね。でも、どれが当たりか分かっていないのに、どうやってその1本だけを狙うんですか。
ねこ博士
いい問いの立て方だ。答えはこうだよ。私たちは当たりが「どれ」かを知らないが、当たりを「見分ける箱」は持っている。電話番号の例なら、名前を1つ渡されて「この人の番号は探している番号か」と聞けば、はい・いいえは即答できる。これがオラクルだ。前回と同じ道具だね。
グローバーの方法は、この箱を使ってたった2手を何度も繰り返す。
ねこ博士
まず準備。全部の量子ビットに H を当てて、N 個の候補すべてに同じ長さの矢印を立てる。長さは √N分の1 だ。2乗して N分の1、それが N 個で合計1になる。
ここから2手を繰り返す。
【第1手・反転】オラクルに聞いて、当たりの行の矢印だけを正反対の向きにする。前回の位相キックバックがそのまま使える。当たりがどれか私たちは知らなくても、箱は知っているから、この操作はできる。
うさ美
でも、向きを変えただけでは長さは変わりません。2乗すれば向きは消えるので、いま測っても当たる確率は N分の1 のまま。目印を付けただけですね。
ねこ博士
まさに目印だ。そして第2手が、その目印を長さの差に変える。
【第2手・平均のまわりの折り返し】全部の矢印の平均を計算して、それを鏡だと思って、すべての矢印を平均の反対側へ折り返す。式で書けば、新しい値＝2×平均 − 元の値。平均より下にあったものは同じだけ上に、上にあったものは同じだけ下に移る。
うさ美
なるほど、当たりだけが平均からうんと離れているから、折り返すと当たりだけが大きく動くんですね。
小さい例で確かめます。候補が4個、当たりが1個。最初はみんな0.5です（0.5の2乗が0.25で、4個足して1）。
第1手：当たりだけ反転して、−0.5、0.5、0.5、0.5。
平均：(−0.5＋0.5＋0.5＋0.5)÷4 ＝ 0.25。
第2手：当たりは 2×0.25 −(−0.5)＝1.0。他は 2×0.25 − 0.5 ＝0。
……できてしまいました。当たりの矢印が1.0、他は全部ゼロ。測れば100%当たりが出ます。4個の中から、箱への質問1回で確実に。
ねこ博士
その通り、候補が4個のときだけは1回で完璧に決まる。きれいだね。
候補がもっと多いときは、1回では届かない。当たりの矢印は少しだけ伸び、外れの矢印は少しだけ縮む。だから2手を繰り返す。反転して折り返し、反転して折り返し……そのたびに当たりが伸びていく。
候補の数 16 くり返した回数 0 当たりが出る確率 6% ちょうどよい回数 3
候補の数
棒1本が候補1つの矢印。上向きが「そのままの向き」、下向きが「正反対の向き」で、棒の長さの2乗がその候補が出る確率。緑の棒が当たり（本来はどれが当たりか分からないが、仕組みを見るために色を付けてある）。点線は全部の矢印の平均。
①を押すと当たりだけが下に反転し、平均がわずかに下がる。②を押すと全部の棒が平均の反対側へ折り返され、平均から大きく離れていた当たりだけが大きく跳ね上がる。繰り返すほど当たりが育つが、行き過ぎると今度は縮んでいく――ちょうどよい回数で止めるのがコツだ。
うさ美
「行き過ぎると縮む」というのが気になります。当たりが育ちきったあとも繰り返したら、せっかく伸びた矢印が減ってしまうということですか。それは変な感じがします。ふつうの探索なら、探し続けても損はしないのに。
ねこ博士
そこが、この方法が「探索」ではなく干渉である証拠だよ。反転と折り返しは、どちらも矢印を回す操作だ。回転を続ければ、いつか行き過ぎて戻ってくる。ちょうど、ブランコを押すタイミングを間違えると勢いが落ちるのと同じでね。
回数の目安は決まっていて、約 0.785×√N 回――円周率πの4分の1が0.785だ。N が100万なら785回くらい。この回数で当たりの確率がほぼ1になり、それを過ぎると下がり始める。
うさ美
100万件が785回。確かにものすごい進歩です。……でも、ひとつ気になります。√N は N より小さいけれど、けた違いに小さいわけではありません。前のステージで出てきた「2ⁿ⁻¹回が1回になる」ような、指数がまるごと消える話とは違いますよね。
ねこ博士
きみは自分でいちばん大事な線引きにたどり着いた。その通りだ。グローバーの加速は2次加速――回数が N から √N になるだけで、指数加速ではない。
たとえば、鍵の候補が2¹²⁸通りある暗号を総当たりで破ることを考えよう。グローバーを使えば2⁶⁴回くらいに減る。128ビットの鍵が実質64ビット分の強さになる、という言い方をする。深刻ではあるけれど、対策は簡単だ――鍵の長さを2倍にすればいい。それで元の強さに戻る。
しかも、この2次加速が限界であることも証明されている。構造のない総当たり探索を、量子コンピュータでこれ以上速くする方法は存在しないんだ。
うさ美
「速くならない限界がある」ことまで分かっているんですね。そう聞くと、量子コンピュータが魔法の箱ではないことがよく分かります。
まとめます。グローバーの方法は、当たりの矢印を反転して目印を付け、平均のまわりで折り返して目印を長さに変える。これを約0.785×√N 回。使うのは、いつもの「打ち消し合いと強め合い」だけで、新しい原理は何も足していない。
ねこ博士
そのまとめで完璧だ。グローバーの方法は「何も構造のない問題」にも効く汎用の道具で、だからこそ効き目が2次加速までにとどまる。
――では、本当に世界を揺るがしたアルゴリズムはどれか。それは、問題に隠れている構造を干渉で暴き出すものだ。次のステージでは、インターネットの安全を支えている暗号を根こそぎにする力を持つ、ショアのアルゴリズムを扱うよ。
横軸が候補の数、縦軸が必要な質問回数（どちらも対数目盛り＝1目盛りで10倍）。ふつうのコンピュータは候補が10倍になれば回数も10倍になるが、グローバーの方法では約3.2倍にしか増えない。差は確かに大きいが、傾きが半分になっただけで、指数の壁が消えたわけではない。次のステージで扱うショアのアルゴリズムは、この図の直線そのものを別の形に変えてしまう。
【グローバーの探索 ― 振幅増幅】 ・問題：構造のない N 個の候補から当たり1個を探す。ふつうのコンピュータは平均 N/2 回、最悪 N 回の質問が必要（これが限界であることも証明済み） ・準備：全候補に H を当て、すべての矢印を長さ √N分の1 にそろえる ・第1手（反転）：オラクルで当たりの行の矢印だけ正反対の向きにする（位相キックバック）。長さは変わらず、目印が付くだけ ・第2手（平均のまわりの折り返し）：新しい値＝2×平均 − 元の値。平均から大きく外れた当たりだけが大きく伸び、外れは少しずつ縮む ・くり返す回数は約 0.785×√N 回（πの4分の1×√N）。行き過ぎると確率は下がる――回転だから ・加速は2次まで（N → √N）で、指数加速ではない。128ビット鍵の総当たりは実質64ビット分になるが、鍵長を2倍にすれば対策できる
確認クイズ

Q1. 候補が4個、当たりが1個。全部の矢印を0.5にそろえてから、当たりを反転し、平均のまわりで折り返した。当たりの矢印の長さは？

正解！ 反転後は −0.5、0.5、0.5、0.5 で平均は0.25。折り返しの式「2×平均 − 元の値」を使うと、当たりは 0.5 −(−0.5)＝1.0、外れは 0.5 − 0.5 ＝ 0。候補が4個のときだけ、1回で確率100%に到達する。

Q2. グローバーの方法で、ちょうどよい回数を過ぎても繰り返し続けるとどうなる？

正解！ 反転と折り返しは矢印を回す操作なので、回し続ければ行き過ぎて戻ってしまう。だから約0.785×√N 回で止めるのが肝心。「探すほど得をする」ふつうの探索とはまったく別の原理――干渉であることの証拠だ。

Q3. グローバーの加速について正しい説明は？

正解！ 100万件が約1000回になるのは大きな進歩だが、指数の壁が消えたわけではない。だから128ビット鍵の暗号も、鍵長を2倍にすれば安全性を取り戻せる。構造のない探索でこれ以上速くする方法が存在しないことも証明されている。
