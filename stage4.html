STAGE 4量子ビットを組み立てる
実機の中身
🎯 ミッション
前回の2つの法則（閉じ込め＝階段、矢印の時計法則）を使って、チップの上に量子ビットを組み立てよう。部品ひとつひとつが「なぜ要るのか」を、義務教育の理科とこの旅の知識だけで説明できれば合格。
未達成
ねこ博士
道具がそろったから、今日はチップの上に量子ビットを組み立てよう。いちばん普及している超伝導方式だ。
出発点は、素朴な電気回路。部品は2つで、電気をためる部品（コンデンサ）と、電流を流し続けようとする部品（コイル）を輪にする。すると、たまった電気がどっと流れ、流れすぎて反対側にたまり、また戻る――電気が行ったり来たりする振り子ができあがる。理科の振り子の、電気版だよ。
うさ美
読めてきました。前回の法則1を使うんですね。電流も電子の流れで、電子は波。この振り子回路は、電流の波を小さな輪の中に閉じ込めている。だったら弦と同じで、生き残れる振動パターンはとびとび――エネルギーの階段が現れるはず。
……でも、それなら変です。スマホにもラジオにも振動する回路は入っているのに、階段の話なんて聞いたことがありません。ふつうの回路は、どう見ても連続的になめらかに動いています。なぜ実験室の回路にだけ階段が見えるんですか？
ねこ博士
最高の疑問だ。答えは「ふつうの回路では、階段を隠す敵が2ついる」。
敵その1は、電気抵抗。ふつうの金属では、電子は進むたびに金属の原子にぶつかって、振動のエネルギーはあっという間に熱になって逃げる。前回の階段の選別は「波が何度も往復して自分自身と干渉する」ことで起きるのだった。数回の往復で擦り切れてしまう波には、選別が働く暇がない。
敵その2は――これは、きみが前の旅でいちばんよく知っている敵だよ。まわりの温かい世界は、飛び回る粒子と電磁波の嵐だ。それが回路に絶えずぶつかると、何が起きるか。
うさ美
手がかりですね。ぶつかった粒子の一つひとつが、回路の状態の手がかりを持ち去っていく。手がかりが漏れ続ければ道筋の区別がついて、干渉は死ぬ――デコヒーレンスです。階段の選別も重ね合わせも、干渉があってこそなのに、温かい環境はそれを絶え間なく壊し続ける。
だから冷やすんですね。冷やせば嵐そのものが静まる。
ねこ博士
その通り。だから実機は、絶対零度よりわずか100分の1度ほど高いだけの温度（約−273.14℃）まで冷やされている。
そして冷やすと、敵その1にも思わぬ贈り物が届く。超伝導だ。ある種の金属は、極低温で電気抵抗が完全に、本当にゼロになる。このとき金属の中では、電子たちが2個ずつペアを組み、全体が足並みをそろえてたった1つの波として流れるようになる。
――正直に断っておくと、「なぜ冷やすとペアを組むのか」は、この旅では説明しない。それだけで丸ごと一つの旅になる大学レベルの難問で、発見（1911年）から理論の完成（1957年）まで半世紀かかったほどだ。今日は「実験で完全に確立した事実」として借りてくる。借り物はこの1つだけだよ。
うさ美
分かりました、そこは事実として受け取ります。
整理すると――冷やしたことで、②環境の嵐が静まって手がかりの漏れが止まり、①超伝導で抵抗が消えて、電流の波が擦り減らずに何億回でも往復できるようになった。閉じ込めの選別が働く条件がそろったから、ついに電流の波の階段が現れる。ここまでは前回の法則1のままです。
では、その階段の間隔はどうなっていますか？ 前回、「間隔の並び方は入れ物しだい」と聞きました。
ねこ博士
痛いところを突かれた。この振り子回路の階段は、全段が同じ間隔なんだ。理由は、理科で習ったあの性質――振り子の等時性だよ。振り子は、揺れが大きくても小さくても、1往復にかかる時間が同じだった。電気の振り子も同じで、揺れの大小によらずリズムがただ1つ。リズムが1種類しかない入れ物では、階段は同じ高さで積み上がる。
そして、それでは困る。1段目に上げる操作が、2段目・3段目に上げる操作と同じになってしまう。下2段だけを量子ビットとして使いたいのに、全部の段が同じ切符で乗れてしまうんだ。
うさ美
なら、等時性をわざと壊せばいいのではありませんか。ブランコは、小さく揺れるときと大きく漕ぐときで1往復の感じが変わります。「揺れの大きさでリズムが変わる振り子」に作り替えれば、段差が不揃いになって、下2段だけを狙えるはずです。
ねこ博士
まさにそれをやる部品が、この方式の心臓部ジョセフソン接合だ。2枚の超伝導体で、ごく薄い絶縁の膜を挟んである。ふつうなら電気は絶縁膜を通れないが、超伝導の波は膜のむこうにしみ出して通り抜ける（波は壁際でぷつりとは消えない）。この通り道には妙な性質があって、流れる電流が大きいほど、通りにくくなる。
つまり、コイルの代わりにこれを入れた振り子は、揺れが大きいほどリズムが変わる――きみの言った「等時性を壊した振り子」そのものだ。階段の間隔は不揃いになり、いちばん下の段差にぴったりの操作は、上の段には効かない。下2段だけが選び出せる。これが |0⟩ と |1⟩、この回路の名はトランズモンだ。
縦方向がエネルギー。左の「ただの振動回路」は段の間隔がすべて同じなので、1段目に上げるためのエネルギーが2段目・3段目へのはしごにもなってしまい、2つの状態を選び出せない。右はコイルの代わりにジョセフソン接合を入れた回路（トランズモン）。段の間隔が不揃いになるため、いちばん下の段差にぴったり合わせたエネルギーは、下2段の行き来しか起こせない。こうして無限にある段の中から |0⟩ と |1⟩ の2段だけが「使える状態」として切り出される。
うさ美
次はゲートです。「1段目の段差にぴったりの操作」と言いますが、その操作の実体は何ですか。段差は「エネルギーの差」で、操作は……何をどう合わせるんですか。
ねこ博士
ここで前回の法則2、矢印の時計法則が主役になる。|0⟩ の矢印と |1⟩ の矢印は、エネルギーが違うぶん回る速さが違うのだった。だから2つの状態のあいだには、「段差に比例したリズムの差」がある。この回路では、そのリズムは1秒に数十億回――スマホの電波に近いマイクロ波の速さだ。
そこで、そのリズムとぴったり同じ周波数で振動する電波を回路に当てる。すると、電波の押しのタイミングが、2つの矢印のリズムの差と毎回そろう――ブランコを、揺れに合わせて押すのと同じだ。押しが積み重なって、|0⟩ と |1⟩ のあいだの乗り移りがどんどん進む。共鳴だね。
逆にリズムがずれた電波は、押すたびに向きが食い違って、押しが自分どうしで打ち消し合う。効かない。――「ぴったりだけが効く」の正体も、結局は干渉なんだ。
うさ美
「乗り移りが進む」なら、進み具合は当てた時間で変わるはずです。……ということは、電波を当てる時間の長さで、矢印の混ざり具合を自由に選べる。途中で止めれば |0⟩ と |1⟩ が五分五分（H の混ぜ方）、ちょうど乗り移り切るまで当てれば入れ替え（X）。ゲートの正体は、長さを精密に決めた電波パルスを1発撃つことですか。
ねこ博士
その通り、自力でゲートの設計思想までたどり着いたね。実機ではパルス1発が数十ナノ秒（1億分の数秒）。H と X は、同じつまみの止め位置の違いにすぎない。CNOT のような2量子ビットのゲートは、隣り合う2つの回路を配線でつないで、結合を一瞬だけ働かせるパルスを撃つ。
そして、ここが大事な点だ。パルスは回路の波全体に働く。矢印の表は波の成分帳簿だから、|0⟩ 成分と |1⟩ 成分を「順番に」処理する余地は、そもそも存在しない。装置に「成分を1つずつ触るボタン」は無いんだ。あとのステージで効いてくるから、覚えておいてほしい。
|0⟩の矢印 1.00 |1⟩の矢印 0.00 0が出る確率 100% 1が出る確率 0%
パルスの時間
スライダーが「段差にぴったりの周波数のマイクロ波を当て続けた時間」。|0⟩ から出発して、当てるほど波は上の段へ移っていき、矢印の表が連続的に書き換わる。途中（4分の1周）で止めれば五分五分＝Hにあたる混ぜ方、半周ぶん当てれば完全な入れ替え＝X。さらに当て続けると1周して元に戻る。ゲートの正体は「パルスの長さの設計」であり、H と X は同じつまみの止め位置の違いにすぎない。実機ではこの1周が数十ナノ秒で回る。
うさ美
最後は測定です。「読み出すと0か1が出る」の実物は、何をしているんですか。
ねこ博士
量子ビットの隣に、読み出し専用の小さなマイクロ波の空洞を付けておく。空洞は「決まった音程で鳴る笛」のようなもので、決まった周波数の電波だけがよく響く。
ここで面白いのは、隣の量子ビットが |0⟩ か |1⟩ かで、この笛の音程がごくわずかに変わることだ。コップに水を注ぐと、量で音程が変わるのと似ている――空洞の波と量子ビットの波は隣どうしで押し合っていて、相手の状態が「入れ物の事情」を少し変えるからだ。
そこで弱い電波を空洞に通して、音程の変化を読み取れば0か1かが分かる。そして――前の旅の言葉で言えば、その電波に手がかりが乗って外の世界へ出た瞬間、道筋の区別がついて、状態は出た方に確定する。測定装置とは、手がかりの漏れ口を、わざと1か所だけ作ってある小窓なんだよ。ふだんは全力で密閉している箱の、読みたいときだけ開ける窓だ。
うさ美
組み立ての全体を、部品の「なぜ」ごとにまとめます。
①振り子回路――電流の波の入れ物。
②冷却――環境の嵐を静めて手がかりの漏れを止め（前の旅のデコヒーレンス対策）、超伝導で抵抗を消して波が何億回も往復できるようにする。これで法則1が働き、階段が現れる。
③ジョセフソン接合――等時性を壊して段差を不揃いにし、下2段だけを |0⟩ |1⟩ として切り出す。
④ゲート――法則2より、段差＝リズムの差。ぴったりのリズムの電波パルスで乗り移りを起こし、当てる時間で混ざり具合を決める。
⑤測定――隣の笛の音程の変化として、手がかりをわざと1か所から外に出す。
……ぜんぶ、波と干渉と手がかりの言葉だけで組み上がりました。
ねこ博士
見事な組み立てだ。方式は超伝導だけではないことも添えておこう。電磁場の罠に浮かべたイオンのエネルギーの段を使い、レーザー光のパルスで操る方式。レーザーのピンセットで原子を1個ずつ並べる中性原子方式。光そのものを使う方式。役者は違っても、「とびとびの2段を選ぶ・波の重ね合わせを保つ・共鳴パルスで操る」という骨組みはぜんぶ同じだ。
そして気づいているね――この機械は、何十億個の電子の波を、光子1個にも乱されないよう守り続けなければならない。その戦いの全貌は旅の最後に。次のステージでは量子ビットを2個に増やして、この旅の主役級の現象を作ってもらう。
【量子ビットの組み立て ― 部品と「なぜ」の対応表】 ・振り子回路（電気をためる部品＋流し続ける部品）＝電流の波の入れ物 ・冷却（約−273.14℃）：①環境の嵐を静めて手がかりの漏れ（デコヒーレンス）を止める ②超伝導で抵抗ゼロに（電子がペアを組み1つの波になる――理由は大学レベルのため事実として借用）。波が何億回も往復でき、閉じ込め＝階段の選別が働く ・振り子の等時性のせいで階段は等間隔になり、下2段を選べない → ジョセフソン接合（電流が大きいほど通りにくい）が等時性を壊し、段差を不揃いに → 下2段が |0⟩ |1⟩（トランズモン） ・ゲート＝時計法則より段差はリズムの差（数ギガヘルツ）。ぴったりのリズムのマイクロ波パルスで共鳴させ、当てる時間で混ざり具合を設計（H と X は止め位置の違い、1発数十ナノ秒）。ずれたリズムは押しが打ち消し合って効かない ・パルスは波全体に働く。成分を1つずつ触る手段は存在しない ・測定＝隣の空洞（決まった音程の笛）の音程が量子ビットの状態でわずかに変わる。その変化として手がかりをわざと1か所から外へ出す小窓 ・他方式（イオン・中性原子・光）も骨組みは同じ：とびとびの2段＋波の重ね合わせ＋共鳴パルス
確認クイズ

Q1. 量子ビットを絶対零度近くまで冷やす理由として正しいのは？

正解！ 温かい環境は粒子と電磁波の嵐で、ぶつかるたびに手がかりを持ち去って干渉を殺す。また、ふつうの金属では抵抗が波をすぐ擦り減らしてしまい、閉じ込めの選別（＝階段）が働く暇がない。冷却はこの2つの敵を同時に黙らせる。

Q2. ジョセフソン接合が果たしている役割は？

正解！ 等時性のままだと階段が等間隔で、1段目に上げる操作が上の段への操作と同じになってしまう。接合は「電流が大きいほど通りにくい」性質でリズムを揺れの大きさに依存させ、いちばん下の段差だけを固有のものにする。抵抗ゼロは超伝導の仕事だ。

Q3. 測定（読み出し）の実物は？

正解！ 空洞の波と量子ビットの波は押し合っていて、相手が|0⟩か|1⟩かで笛の音程がわずかにずれる。その変化を乗せた電波が外に出た瞬間、手がかりが漏れて状態は確定する。測定装置は「手がかりの漏れ口を1か所だけわざと作った小窓」だ。
